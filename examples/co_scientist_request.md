# Co-Scientist 研究输入模板

用途：使用“假设比较”职责，提出并比较解释已有观察的研究假设。

这是供官方 Hypothesis Generation 网页使用的输入模板，不是程序配置文件。需要先取得 Co-Scientist 访问权限。请填写方括号内容，并删除不适用的栏目。

## 本次任务与输出

请提出并比较 3 个可检验的机制假设，并按以下结构回答：

1. 用一句话说明每个假设。
2. 列出支持该假设的直接依据及可访问的出处。
3. 说明它能解释哪些已知观察，还有哪些现象不能解释。
4. 列出会实质改变判断的相反证据或关键未知事项。
5. 为每个假设提出一个最小的区分实验：需要的比较组、主要测量、预期结果，以及什么结果会降低对该假设的支持。
6. 用表格比较证据充分程度、可检验性、与现有条件的适配程度和新颖性，并解释优先顺序。
7. 最后建议先做哪一个实验，说明它为什么能有效区分候选解释。

请把系统的相对排名和真实实验结果分开说明。不要把排名分数解释成成功概率。若已有资料已经回答问题，请直接指出对应证据，不必为了凑足 3 个候选而重复已有结论。
